## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Открыть в браузере адрес, который выведет Vite (обычно http://localhost:5173).

## Что реализовано

- вход с проверкой учётных данных (`GetStateInstance`);
- создание чата по номеру телефона: `8 999 123-45-67` → чат `79991234567@c.us`;
- отправка текстовых сообщений (`SendMessage`);
- получение сообщений через HTTP API (`ReceiveNotification` + `DeleteNotification`);
- статусы исходящих сообщений: отправляется / отправлено / ошибка;
- список чатов с последним сообщением.
